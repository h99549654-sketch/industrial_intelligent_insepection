# industrial_intelligent_inspection
工业设备智能巡检运维平台
SpringCloud Alibaba微服务后端，搭配鸿蒙移动端。运维人员扫码完成设备巡检、故障报修、工单流转、设备状态监控。

## ✨项目介绍
面向工厂运维人员，解决传统人工巡检漏检、故障上报不及时等问题。运维人员使用鸿蒙设备扫码，完成设备巡检打卡、异常上报，工单自动流转分配维修人员，实现设备全生命周期运维管理。

## 🛠技术栈
后端：Java + SpringCloud Alibaba + MyBatis + MySQL
移动端：HarmonyOS鸿蒙
测试工具：Postman、JMeter、Fiddler、JUnit、ADB、禅道

## 📦核心模块
1. 设备管理：维护设备基础信息，绑定二维码
2. 巡检任务：管理员下发巡检计划，移动端扫码巡检
3. 工单报修：异常提交报修、工单流转、维修闭环
4. 数据统计：查询巡检、故障历史记录
5. 权限管理：区分管理员、巡检员、维修人员角色

## 🙋个人职责
1. 参与后端微服务接口开发，负责巡检任务、故障报修工单模块，借助AI辅助编写代码，人工校验调试。
2. 接口自测：使用Postman设计测试用例，完成接口功能、边界、异常场景测试。
3. 性能优化：JMeter对设备查询接口压力测试，参与SQL评审，提出索引优化建议，减少查询耗时。
4. 联调测试：Fiddler抓包定位前后端问题；ADB+模拟器调试鸿蒙端，禅道记录跟踪缺陷。
5. 借助AI辅助编写Newman自动化脚本，人工校验调试，批量执行接口回归测试。
